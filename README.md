# apple_earnings_analysis
This project analyzes 4.7 (approx 5years) of Apple Inc. (AAPL) quarterly earnings announcements using Python and PostgreSQL to examine the relationship between EPS and revenue surprises and short-term stock-price performance.
Developed as a proof of concept for a financial new publication seeking to produce data driven articles on market reaction to company news, the analysis examines 20 earnings announcements
